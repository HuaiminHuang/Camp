

# 🎯 TopK问题

给定一个无序数组 `nums` 和整数 `k`，
返回其中最大的 k 个元素（top-k）。

---

## 一、三种常见思路概览

| 方法    | 思想           | 平均复杂度        | 空间复杂度 | 是否原地     | 适用场景             |
| ----- | ------------ | ------------ | ----- | -------- | ---------------- |
| ① 遍历法 | 每次扫描取最大      | O(n·k)       | O(1)  | ✅        | k 很小，n 很小        |
| ② 排序法 | 排序整个数组       | O(n log n)   | O(1)  | ✅        | n 不是很大，需要排序结果    |
| ③ 堆法  | 维护一个大小为 k 的堆 | ✅ O(n log k) | O(k)  | ❌（堆额外结构） | n 很大、k 很小的情况（推荐） |

---

## 二、方法 1：遍历法（暴力法）

思路很简单：

1. 每次在数组中找到当前最大值；
2. 删除它；
3. 重复 k 次。

示意代码：

```python
def topk_brute(nums, k):
    res = []
    for _ in range(k):
        m = max(nums)
        res.append(m)
        nums.remove(m)
    return res
```

复杂度分析：

* 每次 `max()` 遍历 O(n)
* 做 k 次 → 总复杂度 **O(n·k)**
  当 k 接近 n 时，退化为 O(n²)

> 🧱 非常低效，不适合大规模数据。

---

## 三、方法 2：排序法（Sort）

直接对整个数组排序：

```python
def topk_sort(nums, k):
    nums.sort(reverse=True)
    return nums[:k]
```

复杂度：

* 快排 / Timsort：O(n log n)
* 只取前 k 项 → 仍然要完成整个排序（多做了没必要的比较）

适用：

* 当 n 不是很大；
* 或者确实还需要排序结果（比如输出全局排名）。

> ⚠️ 这一步“超额”了，因为为了得到前 k 个最大值，没必要让整个数组有序。

---

## 四、方法 3：堆法（Heap）✅ 高效之选

核心思想：

> 只维护一个**大小为 k 的最小堆**。
> 堆顶是当前最小的 top-k 元素中的最小值。

### 过程：

1. 遍历整个数组；
2. 若堆未满（<k），直接插入；
3. 若堆已满，且当前元素 > 堆顶 → 弹出堆顶并插入当前元素；
4. 最终堆中就是 top-k。

---

### 示例：

```
nums = [5, 1, 8, 3, 9, 4, 7], k = 3
```

堆变化过程（最小堆）：

| 步骤 | 当前元素 | 堆内容（小顶堆） | 操作          |
| -- | ---- | -------- | ----------- |
| 1  | 5    | [5]      | 入堆          |
| 2  | 1    | [1,5]    | 入堆          |
| 3  | 8    | [1,5,8]  | 入堆（堆满）      |
| 4  | 3    | [3,5,8]  | 3>1 → 弹出1入3 |
| 5  | 9    | [5,8,9]  | 9>3 → 弹出3入9 |
| 6  | 4    | [5,8,9]  | 4<5 → 忽略    |
| 7  | 7    | [7,8,9]  | 7>5 → 弹出5入7 |

最终 top-3 = [7,8,9]

---

### 代码实现（Python 小顶堆）

```python
import heapq

def topk_heap(nums, k):
    heap = []
    for num in nums:
        if len(heap) < k:
            heapq.heappush(heap, num)
        else:
            if num > heap[0]:
                heapq.heapreplace(heap, num)
    return heap
```
### 🔍 工作机制：

1. 堆最开始是空的；
2. 每次遇到新数：

   * 如果堆未满（<k），直接入堆；
   * 如果堆已满：

     * 只有当 `num > heap[0]`（堆顶最小）时，替换堆顶；
     * 否则跳过该元素；
3. 最终堆中保存着 **当前见过的最大 k 个数**。
---

### 复杂度分析

| 操作     | 次数  | 单次复杂度    | 总计         |
| ------ | --- | -------- | ---------- |
| 插入/弹出堆 | n 次 | O(log k) | O(n log k) |

因为 k ≪ n（典型 top-k 场景：如 k=10, n=10⁶），
则 O(n log k) ≈ O(n)。

---

## 五、直观总结

| 方法   | 主要思想       | 时间复杂度          | 适合场景              |
| ---- | ---------- | -------------- | ----------------- |
| 遍历法  | 每次找最大      | O(n·k)         | 小数组               |
| 排序法  | 全排序再取前 k   | O(n log n)     | 结果要排序             |
| ✅ 堆法 | 维护大小为 k 的堆 | **O(n log k)** | n 大、k 小的 top-k 查询 |
| 快速选择 | 基于分区选择     | O(n) 平均        | 一次性找 top-k        |
