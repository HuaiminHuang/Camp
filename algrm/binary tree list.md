# **具体展开解释递归执行过程**

## 🌳 示例树结构

假设输入的数组为：

```python
arr = [1, 2, 3, 4, 5, 6, 7]
```

对应的二叉树结构如下：

```
          1(0)
        /     \
     2(1)     3(2)
    /   \     /   \
  4(3) 5(4) 6(5) 7(6)
```

括号中的数字是数组下标。

---

## 🧩 你的 DFS 实现逻辑再看一遍：

```python
def dfs(self, i, order):
    if self.val(i) is None:
        return
    if order == "pre":
        self.res.append(self.val(i))  # step1: 前序 → 先访问根
    self.dfs(self.left(i), order)     # step2: 遍历左子树
    if order == "in":
        self.res.append(self.val(i))  # step3: 中序 → 左后访问根
    self.dfs(self.right(i), order)    # step4: 遍历右子树
    if order == "post":
        self.res.append(self.val(i))  # step5: 后序 → 左右都遍历完再访问根
```

每种遍历，其实只是这五步中“访问根节点”的位置不同。

---

## 🧠 一、前序遍历（pre-order）

前序遍历规则：**根 → 左 → 右**

也就是在“递归左子树”之前先访问当前节点。

调用 `tree.pre_order()` 时：

```python
self.dfs(0, order="pre")
```

递归展开过程如下：

```
dfs(0): 节点=1 → 访问1
  dfs(1): 节点=2 → 访问2
    dfs(3): 节点=4 → 访问4
      dfs(7): 越界，返回
      dfs(8): 越界，返回
    dfs(4): 节点=5 → 访问5
      dfs(9): 越界
      dfs(10): 越界
  dfs(2): 节点=3 → 访问3
    dfs(5): 节点=6 → 访问6
    dfs(6): 节点=7 → 访问7
```

访问顺序：

```
1, 2, 4, 5, 3, 6, 7
```

🟢 **根节点最先访问，每进入一个节点立刻记录。**

---

## 🧩 二、中序遍历（in-order）

中序遍历规则：**左 → 根 → 右**

也就是先递归左子树，再访问自己，再递归右子树。

调用：

```python
self.dfs(0, order="in")
```

展开：

```
dfs(0): 节点=1
  dfs(1): 节点=2
    dfs(3): 节点=4
      dfs(7): None
      dfs(8): None
      访问4
    访问2
    dfs(4): 节点=5 → 访问5
  访问1
  dfs(2): 节点=3
    dfs(5): 节点=6 → 访问6
    访问3
    dfs(6): 节点=7 → 访问7
```

访问顺序：

```
4, 2, 5, 1, 6, 3, 7
```

🟠 **根节点在中间访问，先“左子树走到底”，再回来访问根。**

---

## 🔵 三、后序遍历（post-order）

后序遍历规则：**左 → 右 → 根**

也就是要等左右子树都遍历完之后，最后访问当前节点。

调用：

```python
self.dfs(0, order="post")
```

递归展开：

```
dfs(0): 节点=1
  dfs(1): 节点=2
    dfs(3): 节点=4 → 访问4
    dfs(4): 节点=5 → 访问5
    访问2
  dfs(2): 节点=3
    dfs(5): 节点=6 → 访问6
    dfs(6): 节点=7 → 访问7
    访问3
  访问1
```

访问顺序：

```
4, 5, 2, 6, 7, 3, 1
```

🔵 **根节点最后访问：必须等到左右孩子都递归完才轮到它。**

---

## 🔍 四、总结记忆规律

| 遍历类型 | 访问顺序      | 递归访问时机    | 特点             |
| ---- | --------- | --------- | -------------- |
| 前序遍历 | 根 → 左 → 右 | 一进入节点就访问  | 常用于复制树、序列化     |
| 中序遍历 | 左 → 根 → 右 | 访问左完后再访问根 | 对 BST 来说可得有序序列 |
| 后序遍历 | 左 → 右 → 根 | 最后才访问根    | 常用于删除树、计算子树和   |

## 🧭 五、递归的直觉

每次递归就像一个“小机器人”：

* 它来到一个节点；
* 决定“现在访问自己”还是“先去找孩子”；
* 递归调用左孩子（又一个机器人进去）；
* 返回后再决定是否访问自己；
* 再去右孩子；
* 最后返回上一层。

**三种遍历只是这个访问点放在了不同的阶段。**
