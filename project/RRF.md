# RRF（Reciprocal Rank Fusion）

## 🌐 一、背景与动机

在 **RAG（Retrieval-Augmented Generation）系统** 中，检索模块的核心任务是从知识库中找出与查询（query）最相关的文档或片段（passages）。  
常见的检索器包括：
- **BM25 / TF-IDF**：基于关键词统计的传统稀疏检索；
- **Dense Retriever（如 Sentence-BERT, E5, GTR）**：基于语义相似度的向量检索；
- **Hybrid Retriever**：融合稀疏与稠密检索结果。

问题在于——不同检索器的“相似性得分”量纲不同、排序风格不同，直接加权融合会导致结果偏移。  
此时，**RRF（Reciprocal Rank Fusion）** 提供了一种 **简单而鲁棒的排序融合方法**，不依赖原始得分，只依赖排名位置。

---

## ⚙️ 二、RRF 的定义与公式

RRF（Reciprocal Rank Fusion）是一种**基于排名的融合算法**，核心思想是：  
> “排名越靠前的文档，权重越大；多个检索器共同推荐的文档排名更靠前。”

### **公式定义：**

假设我们有 $n$ 个不同的检索模型（或检索策略），  
对于文档 $d$ 在第 $k$ 个检索器中的排名为 $r_k(d)$，  
则 RRF 的综合得分为：

$$\text{RRF}(d) = \sum_{k=1}^{n} \frac{1}{k + r_k(d)}$$

其中：
- $r_k(d)$ 为文档 $d$ 在第 $k$ 个检索器结果中的排序位置（rank，越小越靠前）；
- $k$ 是一个平滑常数（通常取 60）；
- 如果某个检索器没有返回该文档，则忽略该项。

最终，所有文档按照 $\text{RRF}(d)$ 得分降序排列。

---

## 🧮 三、计算示例

假设有两个检索器（BM25 与 Dense Retriever），对于同一 query：

| 文档 | BM25 排名 | Dense 排名 |
|------|------------|-------------|
| d1 | 1 | 10 |
| d2 | 5 | 2 |
| d3 | 20 | 3 |

设平滑常数 $k=60$，则：

$$\text{RRF}(d1) = \frac{1}{60+1} + \frac{1}{60+10} = 0.0164 + 0.0145 = 0.0309$$

$$\text{RRF}(d2) = \frac{1}{60+5} + \frac{1}{60+2} = 0.0154 + 0.0159 = 0.0313$$

$$\text{RRF}(d3) = \frac{1}{60+20} + \frac{1}{60+3} = 0.0125 + 0.0158 = 0.0283$$

最终排序：  
**d2 > d1 > d3**

即：  
虽然 d1 是 BM25 的第一名，但 d2 在两个检索器中都靠前，因此综合排名最高。  
这体现了 RRF 对 **多检索一致性的增强效果**。

---

## 🧠 四、RRF 的核心思想

RRF 并不依赖具体的得分值，而只利用“排名信息”。  
这使它具有以下重要特性：

1. **鲁棒性高**：不同模型的分数尺度不同（如余弦相似度 vs BM25 得分），RRF 不受影响；
2. **简单易实现**：无需训练或参数调优；
3. **多源融合能力强**：可无缝整合稀疏检索与稠密检索；
4. **奖励共识文档**：在多个检索器中都靠前的文档得分自然高。
